# Marquee (прямоугольное) выделение файлов

Дата: 2026-08-31

## Проблема

В проводнике клиента нет быстрого способа выделить несколько файлов сразу прямоугольником, как в Проводнике Windows. Сейчас доступно только: Ctrl/Meta+клик (поштучное переключение) и Shift+клик (диапазон в списке). Задача — добавить прямоугольное выделение (rubber band / marquee), запускаемое перетаскиванием по пустой области списка.

## Требования

- Драг по пустой области (не по элементу) рисует прямоугольник и выделяет пересечённые элементы.
- Работает во всех режимах просмотра: `table`, `list`, `content`, `tiles`, `small`, `medium`, `large`, `xlarge`.
- Папки выделяются как файлы (одиночный клик по папке по-прежнему открывает её — поведение не меняется).
- Драг, начатый на элементе, сохраняет существующий drag-out в ОС (без изменений).
- Модификаторы: без модификатора — заменить выделение; Ctrl/Meta — добавить к выделению (union).
- Клик по пустой области без перетаскивания сбрасывает выделение (`clearSelection`).
- Автопрокрутка: при перетаскивании к верхнему/нижнему краю контейнера список прокручивается автоматически.
- Escape отменяет активный marquee и возвращает выделение к состоянию на момент старта драга.
- Без новых npm-зависимостей.

## Архитектура

- Новый хук `src-ui/hooks/useMarquee.js`.
- Использование в `src-ui/components/FileList.jsx`.
- Модель выделения из `AppContext` переиспользуется как есть: `replaceSelection`, `toggleSelect`, `clearSelection`. Никаких изменений в контексте.

### Хук `useMarquee`

Входные параметры:
- `containerRef` — ref на scroll-контейнер списка (`.overflow-y-auto`).
- `getItems()` — функция, возвращающая массив `{ path, element }` для хит-теста (построение через реф-карту в FileList).
- `onReplace(paths)`, `onClear()` — колбэки на модель выделения.

Режим `add` (Ctrl/Meta) реализуется внутри хука как `onReplace(union(selectionAtStart, intersecting))` — объединение выделения на момент старта драга с пересечёнными путями. Так уже выделенные элементы не снимаются, и не требуются новые API в `AppContext`.

Внутреннее состояние (ref для цикла + state для отрисовки):
- `marquee` — `{ startX, startY, curX, curY, mode: 'replace' | 'add' }` или `null`.
- `selectionAtStart` — Set путей на момент старта (для отмены по Escape).

Поведение:
1. `pointerdown` на контейнере. Если `e.target` — элемент внутри item (проверка через `closest('[data-item]')`), marquee не стартует. Иначе запоминаем стартовую точку и `selectionAtStart`, делаем `setPointerCapture`.
2. `pointermove` (пока есть захват): обновляем `curX/curY`; при пройденной дистанции > 4px активируем marquee. Отрисовка прямоугольника — оверлей, абсолютно позиционированный относительно контейнера (вьюпорт, не контент). Хит-тест: пересечение `getBoundingClientRect()` каждого видимого item с прямоугольником.
3. Обновление выделения — живое, на каждый кадр:
   - `mode === 'replace'` → `onReplace(intersecting)`
   - `mode === 'add'` → `onReplace(union(selectionAtStart, intersecting))`
4. Автопрокрутка: `requestAnimationFrame`-цикл. Если курсор в пределах ~40px от верхнего/нижнего края контейнера — `container.scrollTop += speed`, где `speed` растёт к краю. После каждого скролла — пересчёт пересечения.
5. `pointerup`: завершить marquee, отпустить захват, остановить rAF-цикл.
6. `pointercancel` / Escape: отменить — вернуть выделение к `selectionAtStart`, убрать оверлей.
7. Клик без движения (> порога нет): `onClear()`.

### Отрисовка прямоугольника

- Оверлей `<div>` с Tailwind-классами (полупрозрачная заливка `bg-nc-accent/20`, граница `border-nc-accent`).
- Позиция: `left/top/width/height` вычисляются из `min/max` координат старта и текущей точки относительно `containerRef.getBoundingClientRect()`.
- `position: absolute` + `pointer-events: none` + `z-index` выше элементов, но внутри контейнера.

### Изменения в FileList.jsx

- На item-корни добавить `data-item` и рефы: `itemRefs = useRef(new Map())` с `ref={(el) => el && itemRefs.current.set(path, el)}`.
- Хук вызывается с `containerRef` (общий для scroll-контейнера), `getItems`, и колбэками `onReplace` → `replaceSelection` и `onClear` → `clearSelection`.
- `containerRef` вешается на scroll-контейнер списка.

## Обработка ошибок и крайних случаев

- Пустой список: marquee не стартует (нет элементов для хит-теста; onClear по клику на пустой области допустим — сбрасывает пустое выделение, безопасно).
- Минимальный порог 4px: исключает случайный запуск при простом клике.
- Драг по вертикали за пределы контейнера вниз/вверх: работает через pointer capture + автопрокрутку; прямоугольник обрезается по границам контейнера.
- `data-item` на корне элемента: не конфликтует с существующими `onClick`/`onDragStart`/`onDoubleClick`.
- Escape в процессе драга: выделение восстанавливается к `selectionAtStart`.

## Тестирование

Тест-инфраструктуры в репозитории нет (нет test-скрипта в package.json, тестов в src-ui нет). Проверка вручную, чек-лист:

1. Таблица/список: марquee на пустом месте выделяет пересечённые строки; Ctrl+марquee добавляет; клик по пустому месту сбрасывает.
2. Сетки (small..xlarge, tiles): марquee по иконкам; частично пересечённые выделяются.
3. Автопрокрутка: драг к нижнему/верхнему краю в длинном списке прокручивает и доселектовывает.
4. Escape: во время драга отменяет и возвращает прежнее выделение.
5. Драг на элементе: по-прежнему drag-out в ОС (не марquee).
6. Клик по папке: по-прежнему открывает папку; марquee по папкам выделяет их.
