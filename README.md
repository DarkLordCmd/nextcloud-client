# NextCloud Client

Десктопный клиент для [NextCloud](https://nextcloud.com) с Rust-бэкендом и фронтендом на Electron + React.

- **Бэкенд:** Rust (`axum`), локальный HTTP-сервер, общается с NextCloud через WebDAV / OCS
- **Фронтенд:** Electron + React + Vite + TailwindCSS
- **Прогресс:** ход операций передаётся по SSE (Server-Sent Events)

```
┌─────────────────────────────────────────────────────┐
│                  Electron (GUI)                      │
│              React + Vite + TailwindCSS              │
│                                                      │
│   LoginForm │ FileExplorer │ FileList │ Toolbar      │
│                      │                               │
│              fetch → localhost:7842                  │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP + SSE
┌──────────────────────▼──────────────────────────────┐
│                  Rust Backend                        │
│            axum HTTP server :7842                    │
│                                                      │
│   auth.rs │ nextcloud.rs │ upload.rs │ download.rs   │
│                      │                               │
│         WebDAV / OCS API requests                    │
└──────────────────────┬──────────────────────────────┘
                       │ HTTPS
              ┌────────▼────────┐
              │  NextCloud      │
              │  Server         │
              └─────────────────┘
```

## Возможности

- Вход по адресу сервера, логину и паролю (данные хранятся в памяти, на диск ничего не пишется)
- Двухпанельный файловый менеджер: дерево папок слева, список файлов справа
- Навигация по breadcrumb, клик по папке — переход внутрь, двойной клик по файлу — просмотр/скачивание
- Сортировка по колонкам (Имя, Размер, Изменён), папки всегда сверху
- Создание папок, удаление, переименование, контекстное меню
- Иконки файлов по MIME-типу
- Горячие клавиши: F5 обновить, Backspace вверх, Del удалить, Ctrl+A выделить всё, Ctrl+U загрузка

### Встроенный просмотрщик
- Фото, видео и аудио — со стримингом и перемоткой через HTTP Range
- PDF — встроенный просмотр Chromium
- txt, md (marked + санитизация dompurify), docx (mammoth), xls/xlsx (SheetJS); старый .doc — кнопка «Скачать»
- Навигация по файлам того же типа: кнопки ◀/▶, клавиши ←/→, колесо мыши (над прокручиваемым содержимым — обычный скролл)
- Масштаб Ctrl+колесо

### Загрузка и скачивание
- Загрузка со стримингом без буферизации в RAM и живыми прогресс-барами (SSE); мультивыбор и drag & drop
- **Chunked upload v2** для файлов больше 8 МБ: параллельные части (4 потока) + сборка на сервере через MOVE, авто-очистка сессии
- Скачивание со стримингом; несколько выбранных файлов качаются параллельно
- Настройки лимитов скорости загрузки/скачивания (КБ/с, по умолчанию выключены)
- Папка по умолчанию для скачивания и опция «спрашивать, куда сохранять» (включена по умолчанию)

### Скорость
- HTTP/2 с адаптивными окнами потока, пул соединений
- Параллельные загрузки (лимит 5) и скачивания (лимит 3)
- Троттлинг SSE-прогресса и кэш листинга папок

### Безопасность
- Сессионный токен на локальном бэкенде (защита от сторонних сайтов/процессов) + ограниченный CORS
- Content-Security-Policy в production-сборке, sandbox-режим рендерера
- Пароль только в памяти; TLS до сервера проверяется стандартно

### Автообновление
- При старте приложение проверяет новые релизы GitHub и предлагает установить (скачивание → установка → перезапуск)
- Кнопка «Check for updates» в настройках (⚙️)

## Требования

- Rust toolchain (rustc 1.85+)
- Node.js 18+ и npm

## Разработка

```bash
npm install
npm run dev        # запускает Vite dev server + Electron (поднимает Rust-бэкенд)
```

## Сборка и упаковка

```bash
npm run build       # release-сборка Rust-бэкенда + Vite-сборка UI
npm run package:win # установщик NSIS (Windows)
npm run package:mac # DMG (macOS)
npm run package:linux # AppImage (Linux)
```

Rust-бинарник встраивается в приложение через `electron-builder` `extraResources`.
Обратите внимание: имя бинарника (`nextcloud-client` vs `nextcloud-client.exe`)
зависит от платформы — при сборке для macOS/Linux поправьте `electron-builder.yml`.

Автообновление работает через провайдер `github` (owner/repo в `electron-builder.yml`).
При публикации релиза обязательно прикладывайте `latest.yml` (генерируется в `dist/`)
вместе с установщиком — файл должен называться так же, как URL в `latest.yml`.

## API (локальный бэкенд)

Все `/api/*` запросы требуют сессионный токен (`Authorization: Bearer <token>`
или `?token=` для SSE и media-тегов).

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/api/auth/login` | Сохранить адрес сервера и учётные данные, проверить соединение |
| `GET` | `/api/auth/status` | Проверить наличие сохранённых учётных данных |
| `POST` | `/api/auth/logout` | Очистить учётные данные |
| `GET` | `/api/files?path=/` | Листинг файлов и папок по пути |
| `GET` | `/api/files/download?path=...` | Стриминг файла; `&inline=1` — `Content-Disposition: inline`, проброс `Range` (перемотка медиа, PDF), `ETag`/`Cache-Control` |
| `POST` | `/api/files/upload?path=...&name=...` | Загрузить файл (сырое тело; большие файлы — chunked upload v2) |
| `DELETE` | `/api/files?path=...` | Удалить файл или папку |
| `POST` | `/api/files/mkdir?path=...` | Создать папку |
| `PATCH` | `/api/files/rename` | Переименовать файл/папку |
| `GET` | `/api/files/progress` | SSE-поток прогресса операций |
| `PUT` | `/api/settings/upload-limit` | Установить лимит скорости загрузки, байт/с (`0` — без ограничения) |
